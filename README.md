# IC Design Lab — HCMUT Website (Preview)

A responsive, dependency-free static research laboratory website for GitHub Pages.

## Preview locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

and visit http://localhost:8000.

## Deploy to GitHub Pages

1. Create the **public** repository `IC-design-lab-HCMUT/ic-design-lab-hcmut.github.io`.
2. Add `index.html`, `assets/style.css` and `assets/site.js` to the repository root.
3. In Settings → Pages, select **Deploy from a branch**, **main**, **/(root)**.
4. Open https://ic-design-lab-hcmut.github.io after deployment completes.

## Important editorial notes

This is a design prototype, not an official factual lab profile. Verify the official laboratory name and description, personnel names/photos, equipment, publications, addresses and contact email before launching. Some project blurbs are brief inferred summaries based on public repository names and must be reviewed.

The page intentionally shows only public GitHub repositories. No external framework is required; Google Fonts is an optional external asset with system-font fallback.
